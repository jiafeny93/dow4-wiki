## What are the Dawn of War IV Tacticus codes?

Two official rewards from the **Dawn of War IV × Tacticus crossover** (announced November 2026, with Snowprint Studios):

1. **`DOW4FRIEND`** — a bonus code for **all** Tacticus players
2. **Thothmek shard code** — a unique per-player code for Dawn of War IV newsletter subscribers

## Code DOW4FRIEND: rewards

<CodeBlock code="DOW4FRIEND" label="Redeem in Tacticus → Settings" />

The universal code grants, per the official announcement:

| Reward | Amount |
|---|---|
| Requisition Order | 1× |
| Blackstone | 50× |
| Coins | 2,000× |

**Limits**: once per player · redeemable until **January 1, 2027**.

## How to redeem Tacticus codes

1. Open **Warhammer 40,000: Tacticus** (free on mobile/PC)
2. Reach the **Home page** tab
3. Open **Settings** — there is a code input text box
4. Enter `DOW4FRIEND` and confirm

> **Prerequisite**: you must have beaten **Battle 15** before the redeem function unlocks — new players need a few sessions first.

## The newsletter code: 130 Thothmek shards

The second reward is exclusive to **Dawn of War IV newsletter subscribers**: a unique code granting **130 Thothmek character shards** — enough to unlock the Necron character in Tacticus.

- Already subscribed? The code arrives in your inbox
- New subscribers receive their unique code **within 72 hours** of signing up
- Signup is via the official Dawn of War IV site ([editions & official links](/guides/editions-preorder/))

Necron fans double-dip here: Thothmek in Tacticus now, the [Awakened Monolith](/factions/necrons/) on [Kronus](/guides/kronus/) December 3.

## Why is Dawn of War IV doing a Tacticus crossover?

Standard launch-window cross-promotion: both games sit under the Games Workshop license, and the crossover seeds DoW4's community into Tacticus (and vice versa) ahead of the **December 3 launch** — Commander Edition players deploy **November 30** ([release times](/guides/release-time/)). Cross-promo rewards like these usually expire on schedule — this one January 1, 2027 — so redeem early ([what else is coming](/guides/roadmap/)).
