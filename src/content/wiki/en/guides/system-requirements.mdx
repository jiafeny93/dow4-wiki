## What are Dawn of War IV's system requirements?

**Officially announced** (publisher announcement, verified 2026-11-16). The game requires a 64-bit processor and operating system.

| Component | Minimum | Recommended |
|---|---|---|
| OS | Windows 11 | Windows 11 |
| Processor | Intel Core i5-10600K / AMD Ryzen 5 2600X | Intel Core i7-12700 / AMD Ryzen 5 7600X |
| Memory | 16 GB RAM | 32 GB RAM |
| Graphics | NVIDIA GeForce GTX 1660 / AMD Radeon RX 5700 | NVIDIA GeForce RTX 3060 Ti / AMD Radeon RX 9060 (8 GB) |
| Storage | 125 GB available space | 125 GB available space |

## Does Dawn of War IV run on Windows 10?

**Yes — but unofficially.** The developers confirmed the game *can* run on Windows 10; Windows 11 is listed in the official requirements because Microsoft has ended official Windows 10 support. If your machine ran the game during the Closed Beta, it will run the full game at launch.

## Does Dawn of War IV run on Linux?

**Unofficially, possibly.** Beta players have reported successfully running the game on Linux, but Linux is not officially supported and ongoing compatibility with future updates is not guaranteed. Treat it as community territory, not a promise.

## Why does the game need 125 GB of storage?

The install is **approximately 100 GB, including around 25 GB of cutscenes**, plus highly detailed units and assets you can zoom in on. The officially listed **125 GB** leaves headroom for future updates and DLC beyond the initial install. Plan your SSD space accordingly — see also [editions & early access](/guides/editions-preorder/).

## Is 32 GB of RAM really required?

No. **16 GB is the true minimum** and the game runs on it. 32 GB is *recommended* for a smoother experience with background applications, and 24 GB systems also work. The recommendation is headroom, not a hard floor.

## Is Dawn of War IV on GeForce NOW?

**Yes — confirmed.** The game will be available on NVIDIA GeForce NOW at launch, letting you stream it from your Steam library through NVIDIA's cloud service — a way in below the hardware bar above. For platforms, the game is otherwise PC-only at launch; see the [crossplay guide](/guides/crossplay/).

## Can I run Dawn of War IV? (quick read)

- **At or above the minimum column** — you're clear for [December 3](/guides/release-time/) (Commander Edition starts November 30)
- **Between minimum and recommended** — expect to tune settings in big 3v3 battles
- **At recommended** — headroom for high frame rates while zoomed into large [multiplayer](/guides/game-modes/) engagements
- **Below minimum** — GeForce NOW is your official fallback, or check the [beginner guide](/guides/beginner-guide/) while you plan an upgrade
