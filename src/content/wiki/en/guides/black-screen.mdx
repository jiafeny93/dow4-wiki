> **Launch-day page.** This troubleshooting page goes live the moment the game unlocks, with fixes verified against real player reports. The prevention checklist below already works today.

## Quick checklist before anything else

1. **Meet the minimum specs** — [official requirements](/guides/system-requirements/) (GTX 1660 / 16 GB / Win 11)
2. **Clear 125 GB on an SSD** — the game needs it ([why](/guides/download-size/))
3. **Update GPU drivers** — day-one drivers land with big launches
4. **Verify game files** — Steam → right-click Dawn of War IV → Properties → Installed Files → Verify
5. **Close RGB/overlay apps** — common launch-day conflicts

## Known causes we will verify at launch

- Driver / overlay conflicts (Discord, MSI Afterburner, GeForce Experience overlays)
- Outdated Windows or missing redistributables
- Overheating in big 3v3 battles ([performance read](/guides/system-requirements/))
- Corrupted install — fixed by file verification
